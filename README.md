VOIDKITE — a neon arena survival shooter. Fly a light-kite through a collapsing nebula, shoot the voidspawn closing in, harvest light shards and chain kills into a ×8 combo. Motes chase, crags split in two, darters telegraph and dash, and every third wave wakes a Warden. Three lives, nova bombs, shield and spread-shot pickups, synthesized sound, and a best score that persists.

## Run it

```sh
node serve.ts
```

Then open http://localhost:8080 — no build step, no network requests, just static files under `game/`.

WASD / arrows fly, mouse aims, hold click or Space to fire, E or right-click spends a nova bomb, P pauses, M mutes.
